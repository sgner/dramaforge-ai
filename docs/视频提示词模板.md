# §0 使用方法

## 0.1 适用场景

- **故事板 prompt** → 喂给 GPT Image 生成 2×N 网格黑白线条分镜图 (人工审稿用)
- **视频 prompt** → 喂给即梦/Sora/Veo 生成 15s 级短片

## 0.2 工作流

```
1. 准备素材 (frame 逐帧分析 / shotlist 镜头表 / 剧本文字)
2. 列视觉清单
3. 镜头合并/拆分
4. 写故事板 prompt
5. 用户审故事板, [通过] / [修改]
6. 写视频 prompt
7. 用户审视频, [通过] / [修改]
8. 进入下一个子单元
```

**严禁跳步** (例外: 用户明确说"直接出视频"或"跳过故事板")。

## 0.3 读模板顺序

- **第一次用**: 完整读 §1 起手式 + §2 核心杠杆 + §8 完整骨架
- **写 prompt 时**: 必读 §1, 按主题查 §3/§4

## 0.4 跨模型兼容 5 条硬约束 (v1.22 必读)

**背景**: 把模板喂给其他大模型 (GPT/Gemini) 时, 隐含约定不显式写入就会失效. 这 5 条必须明示:

### ① 一份 prompt ≤ 15 秒子单元 (长 shotlist 必须拆)

- shotlist ≤ 15s → 一个子单元 (1 份故事板 prompt + 1 份视频 prompt)
- shotlist > 15s → **必须拆分**, 拆分点选戏剧自然断点

❌ 错: 28 秒一次性写 17 镜 (跨子单元混在一份 prompt 里)
✅ 对: 28 秒拆成 2 个子单元 (15s + 13s), 各自一份独立 prompt

### ② 视频镜头数 = 故事板有内容镜数 (精确等于, v1.26 + v1.27)

视频 prompt 镜头数必须 **精确等于** 故事板**有内容**镜数 (不算黑屏):

| 故事板状态 | 视频 prompt 镜头数 |
|---|---|
| 8 镜 (8 内容 + 0 黑屏) | **正好 8** |
| 8 镜 (7 内容 + 1 黑屏) | **正好 7** |
| 8 镜 (5 内容 + 3 黑屏) | **正好 5** |

**v1.27-A 故事板对照声明 (强制)**: 视频 prompt 在【镜头列表】之前必须加:

```
【故事板对照声明】上一份故事板共 N 镜 (含 K 镜有内容 + (N-K) 镜黑屏). 本视频 prompt 共 K 镜, 严格对应故事板镜头 1-K. 严禁引用故事板不存在的镜头编号.
```

**强制标编号**: 每镜标 `(对应故事板镜头X)`, **X 必须 ∈ [1, K] 真实范围**:

```
镜头1 (对应故事板镜头1) | ...
镜头2 (对应故事板镜头2) | ...
...
镜头K (对应故事板镜头K) | ...
```

❌ 严禁:
- 故事板 7 内容 → 视频写 10 镜 (自加"闪剪/海报/气氛镜")
- X > K (引用故事板不存在的编号)

✅ X 严格按顺序 1→K

**例外**: 推/拉/横移镜头可以"一镜多动作", 但仍是同一个镜头编号 (见 §4.5)

### ③ 一次调用只输出一个子单元的一份 prompt (v1.24 强化)

**两层硬约束** (缺一不可):
1. 故事板 prompt 和视频 prompt **不能同次输出** (二选一)
2. 多个子单元 **不能同次输出** (例如 1-1 + 1-2 不能一次给)

```
调用 1 → 子单元 1-1 故事板 prompt
   ↓ 用户审 [通过]
调用 2 → 子单元 1-1 视频 prompt (镜头跟 1-1 故事板 1:1 对应)
   ↓ 用户审 [通过]
调用 3 → 子单元 1-2 故事板 prompt
   ↓ ...
```

**总调用次数 = 2 × 子单元数** (例: 9 个子单元 = 18 次调用)

❌ 错: 一次调用同时输出故事板 + 视频 prompt
❌ 错: 一次调用同时输出 子单元 1-1 + 子单元 1-2 (v1.24 新加)
✅ 对: 每次调用只输出 ONE 个子单元的 ONE 份 prompt

**对其他大模型 (GPT/Gemini) 调用必须明示两层约束**:
```
请按 CineForge 模板执行:
- 本次只输出"子单元 1-1"的故事板 prompt
- 不要同时输出视频 prompt
- 不要批量输出 1-2 / 1-3 等其他子单元
```

**Why**: 用户一次审一个子单元才能精准发现问题. 一次给 N 个 → 改 1-1 让 1-2 失效 → 浪费。

### ④ 视频 prompt 镜头描述 = 故事板对应镜头的动态版

| 镜头 | 故事板 (frozen frame) | 视频 prompt (动态) |
|---|---|---|
| 镜头N | `{景别+角度+静态状态} — 主体在位置 X` | `{景别+角度+运动} — 主体【从位置 X 朝 Y 运动】` |

**核心约束**:
- 主体必须跟故事板一致
- 景别必须跟故事板一致
- 位置必须跟故事板一致
- **只加** 运动方向 + 入画动作 + 音效

❌ 错: 视频 prompt 镜头跟故事板内容脱节
✅ 对: 视频 prompt 是故事板的"加上运动 + 音效" 版本

### ⑤ 参考图格式 `@图片N作为XXX` 两层硬约束

**第 1 层**: `@` 后面必须用 **图片数字编号**, 不是具体名

❌ 错: `@童年苏砚作为童年主角` (用了具体名作为图片锚)
✅ 对: `@图片1作为童年主角` (用 @图片N 数字编号)

**第 2 层**: `作为` 后面的 XXX 必须用 **剧本里的具体角色名**, 不是通用职能名

| ❌ 错 (通用职能名) | ✅ 对 (剧本具体名) |
|---|---|
| `@图片1作为童年主角` | `@图片1作为童年苏砚` |
| `@图片2作为母亲` | `@图片2作为苏夫人` |
| `@图片3作为反派` | `@图片3作为百臂阎尊` |

**例外 (群体角色)**: 群体用群体名: `@图片N作为百姓` / `@图片N作为缚骸群`

**标签 ↔ 正文 1:1 一致**: XXX 必须跟正文镜头描述里的角色名一致

❌ 错: 标签`作为童年主角` + 正文`童年苏砚一只眼睛...` (不一致)
✅ 对: 标签`作为童年苏砚` + 正文`童年苏砚一只眼睛...` (一致)

**Why**: 通用名 ("主角") 在视频模型训练数据里没有具体形象, 具体名 ("苏砚") 跟参考图绑得更紧。

**模板示例 vs 实际使用**: 模板里的"主角/反派/百姓" 是抽象化占位符, 实际写 prompt 时**必须替换成剧本里的具体名字**。

# §1 起手式 (核心思维定锚)

## 1.1 翻译员身份, 不是电影导演

**任务**: 把素材 (frame / shotlist / 剧本) **翻译**成 prompt 文字。

**不是**:
- 自己设计镜头节奏
- 自己加视觉签名
- 自己决定每段要不要海报帧

**是**:
- 素材给什么, 翻什么
- 素材没说的, 不加

## 1.2 4 不准则

| 准则 | 含义 |
|---|---|
| **不增** | 不自加海报/收尾/视觉签名 |
| **不减** | 不省略原素材的关键细节 |
| **不改** | 不重新设计镜头节奏/合并/拆分 (除 §4.5 推拉摇可合并外) |
| **不创** | 不自创原素材没有的镜头/角色/动作 |

## 1.3 3 步工作流 (写 prompt 前必跑)

```
步骤 1 [视觉清单] 列出素材范围内每帧/每镜的真实视觉 (一行一帧, Ground truth)
       — frame 素材: 地毯式逐帧看, 不跳
       — shotlist 素材: 逐镜读, 把"内容"+"声音" 列下来
       — 剧本素材: 逐段读, 把场景/动作/角色/道具列下来

步骤 2 [镜头合并/拆分] 按"镜头运动能否一次完成" 决定故事板帧数, 不预设 8 镜或 5 镜

步骤 3 [写 prompt] 严格从步骤 1 的清单生成, 自查"4 不准则", 多余的删
```

**禁止跳步** — 不先列清单就不能写 prompt。

## 1.4 每镜写前自问 3 题

1. **这镜在原素材里有对应吗?** (frame N / shotlist 镜头 X / 剧本第几段)
2. **对应得准吗?** (主体/位置/朝向/构图/镜头是否跟原素材一致)
3. **跟前一镜的差异, 能不能靠一个镜头运动 (推/拉/横移/摇) 一次完成?** (能 → 合并; 不能 → 拆)

## 1.5 "展开" vs "自创" 的边界

- **展开 (允许)**: 剧本说"街市着火, 百姓奔逃" → 翻译成 "中景 平视手持·急摇 — 街市街道, 一群百姓朝镜头方向奔逃, 街道两侧建筑燃烧"
- **自创 (禁止)**: 同上场景, 强加 "大远景拉远收束镜头, 街市废墟为底" — 剧本没说要收束

# §2 视频 prompt 核心杠杆

## 2.1 A 动作驱动, 不只是静态位置

视频 prompt 跟故事板的本质区别: 故事板可以"静态位置", 视频 prompt **每镜必须有"谁在做什么"**。

| ❌ 静态位置 | ✅ 动作驱动 |
|---|---|
| "怪物围拢, 百姓挤于下方" | "怪物**一手抓起百姓塞进嘴里**" |
| "主角仰头朝天" | "主角**仰头嘶吼**, 嘴大张" |

**判断**: 这个镜头的"运动" 是什么? 写不出运动 = 还是故事板思维。

## 2.2 B 群像加"多样化"描述, 防视频模型克隆人

群像写"长相不同, 穿着不同" 等多样化提示。

| ❌ 没多样化 | ✅ 多样化 |
|---|---|
| "一群百姓挤于中央" | "一群**长相不同, 穿着不同**的百姓挤于中央" |
| "怪物群涌动" | "**各自姿态不同**的怪物群涌动" |

## 2.3 C 不重复参考图已定义的外貌 (简化)

参考图标签已经定义了角色外貌, prompt 不必每次重写, 直接用资产名引用。

- ❌ "灰色头骨刻黑色咒文, 头骨上方右侧大红独眼..." (重写参考图已有)
- ✅ "一颗反派本体"

**例外**: 镜头里需要**新状态/新动作** (例如"反派嘴里含主角") 必须写。

# §3 视频 prompt 规范

## 3.1 视频 prompt 整体结构

```
基于@图片1作为故事板
@图片2作为{角色A}
@图片3作为{角色B}
@图片4作为{场景A}
@图片5作为{道具A}

【创建声明】创建此短片 — 不包含任何移动箭头、路径线、镜头分割线

【视觉风格】
- 质感: ...
- 色彩: {主色} ↔ {对比色} (必给对比对)
- 特效家族: ... (题材化物理特效)
- 光线: ...

【镜头列表】(共 N 个镜头, 总时长 X 秒)
镜头1 | {景别+角度+运动} — {画面描述, 含【运动方向】}
        音效: {环境低频} + {细节高频}
镜头2 | ...
...

【风格】电影级别的 CG {题材} 影片

禁止项：文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】
无背景音乐，仅保留环境音与人声；画面禁字幕/文字/水印/Logo；禁止可读文字；禁止超现实夸张；禁止无反作用力动作
```

## 3.2 参考图清单格式

**索引顺序固定**: `故事板 → 角色 → 场景 → 道具`

```
基于@图片1作为故事板              ← 第 1 行用"基于"起头
@图片2作为{角色A}                 ← 后续行省略"基于"
@图片3作为{角色B}
@图片4作为{场景A}
@图片5作为{道具A}

【创建声明】创建此短片 — 不包含任何移动箭头、路径线、镜头分割线
```

**约束**:
- 索引顺序固定
- 同一类群体角色 (如"百姓") 用一张代表图即可
- **敏感词替换时, 参考图标签必须同步替换** (见 §5.6)

## 3.3 镜头描述 — 一句话紧凑动态, 严禁描述尾

每个镜头描述 = `角色/物体 + 动作 + 【运动方向】 + 元素叠加`, 全部压成**一句话**。

**典范写法**:
```
镜头1 | 极端特写 平视慢推 — 主角手臂【从画面顶部垂下】到中央, 苍蝇环绕【朝镜头扑面】飞舞
```

**特征**:
- 一句话, 顶多用一个分号或逗号叠加第二个动态元素
- 有起始位置 + 有动态过程 + **没有结束位置**
- 没有"镜头开始/中段/结束" 显式三段标签

### 严禁描述镜头尾 (核心硬约束)

❌ **错**: "鬼影从画面左侧入画, **停在画面右侧**"
✅ **对**: "鬼影【从画面左侧入画】, 张爪逼近"

**Why**: 视频模型看到"停在 X" 会硬把镜头收在 X 位置, 后续镜头的起始位置就不灵活了。留白给视频模型自由发挥镜尾过渡。

### 不写时间码, 只写"镜头几"

格式: `镜头1 | 镜头描述`, 不要 `镜头1 (0-2s) | ...`

节奏控制走三件事:
1. 镜头数量比例
2. 镜头描述详略 (慢镜头多写细节, 快镜头一句话)
3. 动作快慢词 ("缓缓/渐渐" 慢 vs "猛然/瞬间" 快)

### 入画动作优先, 严禁"悬于/位于" 静态位置

| ❌ 静态位置 | ✅ 入画动作 |
|---|---|
| "骷髅头**悬于画面右上**" | "骷髅头【从画面右上进入】" |
| "饿鬼形**位于画面中景**" | "饿鬼形【从画面右侧入画】" |

## 3.4 方向标【】必标 4 类

方向标【】= 关键运动的空间锚。**必标 4 类**:

1. **入画动作 + 运动方向**
   - 鬼影【从画面左侧入画】, 火星【从画面顶部坠下】

2. **镜头自身运动**
   - 镜头【从主角推进至嘴内】, 镜头【缓慢拉远】

3. **Z 轴 / Y 轴关键运动** (朝镜头/远离镜头/坠下/升起)
   - 苍蝇【朝镜头扑面】, 鬼影【从画面深处朝镜头袭来】

4. **多元素同时运动需要区分方向**
   - 手臂【从画面顶部垂下】到中央, 苍蝇环绕【朝镜头扑面】飞舞

**每镜上限**: 2 个【】

**自然动作不必标**: 单角色简单动作 (转身/张口/含住) 不必加【】, 视频模型已知。

## 3.5 运动方向 6 大类字典

### 1. 深度轴 (Z 轴 — 最关键, 前/后)
- 「朝镜头袭来」/「朝镜头扑面」
- 「远离镜头」/「朝画面深处而去」
- 「从镜头身边掠过」/「在画面深处显形」

### 2. 横轴 (X 轴 — 左/右)
- 「从画面左侧入画」/「从画面右侧入画」
- 「从左横穿到右」/「从右横穿到左」

### 3. 纵轴 (Y 轴 — 上/下)
- 「从画面顶部坠下」/「从画面底部升起」
- 「在镜头上方盘旋」

### 4. 斜向 (复合轴)
- 「朝镜头斜扑」
- 「从镜头侧后方袭来」 (主观跟拍专用)

### 5. 环绕 / 旋转
- 「围绕镜头旋转」/「围绕画面中心物体旋转」

### 6. 静止 + 方向感
- 「凝视镜头」/「背对镜头」/「侧面对峙镜头外」

## 3.6 一镜一信息 (镜头节奏)

**核心规律**: 镜头是"信息释放单元", **每镜只给观众一个新视觉信息**。

### 全知视角 vs 角色视角

| 视角 | 表现 | 后果 |
|---|---|---|
| **全知视角** (错) | 第 1 镜就把"接下来要发生 X" 提前展示 | 后续镜头变成"重复已知", 戏剧张力崩塌 |
| **角色视角** (对) | 跟随角色一起"突然发现", 拐点镜头才揭晓 | 信息累积制造悬念 |

**关键技巧**: 拐点镜头通过**次要载体** (例如角色面部反射光) 先泄密, 不直接拍正面。

### 衍生规则: 一镜一焦点 (不堆元素)

镜头描述不要同时塞 (主角 + 次要角色 + 光线 + 背景)。光线信息放【视觉风格】块, 次要角色靠音效/画外音暗示。

- ❌ "童年主角含泪侧脸位于画面前景, 母亲虚影【从画面深处缓缓显形】立于身后, 暖琥珀光从侧面打入" (3 元素)
- ✅ "童年主角含泪侧脸站在门口" + 音效 "母亲(画外, 耳语): ..." (1 焦点 + 音效暗示)

## 3.7 状态渐变拆多镜 (基础节奏)

天空颜色变化 / 光线异变 / 角色情绪转变 等"过程态", 必须分 2-3 镜递进:

- ❌ 一镜: "天空染朱赭红" (一镜跳到最终态)
- ✅ 三镜: 天空正常夜晚 → 角色面部光从蓝转红 → 天空日食显形

## 3.8 多角色空间锚定 (基础版)

### v1.15-A: 多角色距离用资产锚

**触发条件**: 多角色之间有**明显空间距离**。

**写法**: `[角色] 在距离 [中心角色] X 米外的 [画面方向]`

| 错 (无锚孤立距离) | 对 (锚到中心角色) |
|---|---|
| 追杀者A 在五米外停住 | 追杀者A **在距离主角五米外的画面正前方**停住 |
| 鬼影从远处袭来 | 鬼影从**距离主角十米外的画面深处**朝主角袭来 |

### v1.15-C: 方向词必须加"画面" 前缀消除歧义

**问题**: "追杀者A 的左侧" 有歧义 — A 的身体左侧, 还是镜头视角的左侧?

| ❌ 无前缀 | ✅ 带"画面" 前缀 |
|---|---|
| "在追杀者A 的左侧" | "在追杀者A 的**画面左侧**" |
| "鬼影从右后方袭来" | "鬼影从**画面右后方**袭来" |

**例外**: 角色的身体动作 (例如"举起左手") 是身体本身的左右, 不加"画面"。

## 3.9 群像处理 (自然集合量词 + 多样化)

### 关键判断: 群像的排列方式是不是戏剧关键?

| 群像类型 | 排列方式是否关键 | 用什么描述 |
|---|---|---|
| **一般动态群像** (奔逃/涌动/散立/聚集) | 不是 | **自然集合量词**: "一群"/"一片"/"数十只"/"四散"/"涌动"/"散开" |
| **紧贴群像** (合影/仪式/列队) | 是 | "并排"/"肩并肩"/"成行"/"列阵" |
| **围攻群像** | 是 | "环立"/"围成一圈"/"团团围住" |

### 错 ↔ 对 对照

❌ **错** (奔逃/涌动加"并排"):
```
怪物群从画面深处朝画面前景密集涌动, 群体骷髅人形【并排】
```

✅ **对** (自然描述):
```
一群怪物群从画面深处朝画面前景密集涌动, 各自姿态不同
```

### 多样化防克隆

| ❌ 没多样化 | ✅ 多样化 |
|---|---|
| "一群百姓挤于中央" | "一群**长相不同, 穿着不同**的百姓挤于中央" |

## 3.10 音效层格式

每个镜头末尾必给音效行:
```
镜头N | 镜头描述
        音效: {环境低频} + {细节高频} (+ 台词 / 静默 / 名牌音)
```

### 音效结构 (3-4 层)

1. **环境低频**: 远处低频钟鸣 / 神性低频共振 / 地鸣 / 风声
2. **细节高频**: 苍蝇嗡鸣 / 锁链碰撞 / 火苗噼啪
3. **角色声**: 台词 / 嘶喊 / 呼吸 / 心跳
4. **特殊**: 拐点静默 ("极致静默 → 远处低频骤起") / 名牌音 ("「咔」")

### 音效减法

情感镜头 (流泪 / 凝视 / 静止) 用**静默**更有力, 不必每镜都满 3-4 层。

## 3.11 固定文案 (照搬不改)

### 【风格】行 (一句话, 不加后缀)

```
【风格】电影级别的 CG {题材} 影片
```

❌ 错误 (加冗余后缀):
```
【风格】电影级别的 CG 东方玄幻影片, 明清志怪 + 民国街市质感
```

### 【禁止项】+【强制声明】 (一字不动)

```
禁止项：文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】
无背景音乐，仅保留环境音与人声；画面禁字幕/文字/水印/Logo；禁止可读文字；禁止超现实夸张；禁止无反作用力动作
```

### 【创建声明】

```
【创建声明】创建此短片 — 不包含任何移动箭头、路径线、镜头分割线
```

- [ ] 第一行是不是 `基于@图片1作为故事板`?
- [ ] 参考图顺序是不是 `故事板→角色→场景→道具`?
- [ ] 每个镜头是不是一句话, 没有"镜头开始/中段/结束"?
- [ ] 镜头描述有没有"停在 X / 落在 Y" 描述尾?

- [ ] 入画动作有没有用 (不是"悬于/位于")?
- [ ] 多角色镜头有没有锚到中心角色?
- [ ] 方向词前面有没有"画面"前缀?
- [ ] 群像有没有"多样化"描述?

# §4 故事板 prompt 规范

## 4.1 故事板 prompt 整体结构

```
@图片1作为{角色A}
@图片2作为{角色B}
@图片3作为{场景A}
@图片4作为{场景B}

白色故事板。2×4 网格 8 帧黑白线条分镜，黑边框、红墨方向箭头、蓝色中文运镜批注。文字只需要运镜描述，不需要其他内容。

八帧 —— {短片标题} (总时长 X 秒)

镜头1 | {景别+角度+运动} — {画面描述}
镜头2 | {景别+角度+运动} — {画面描述}
...
镜头N | {景别+角度+运动} — {画面描述}

风格： 分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注
```

## 4.2 故事板 8 条硬约束

1. **有内容镜头数灵活, 视题材定**: 不死磕 8 镜, 按 §4.5 推/拉/横移摇能一次完成的合并为一帧, 实战有内容镜头常用 3-8 镜
2. **批注文字只放运镜术语**
3. **风格行固定** (照搬): `风格： 分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注`
4. **段头固定** (照搬): `白色故事板。2×4 网格 8 帧黑白线条分镜，黑边框、红墨方向箭头、蓝色中文运镜批注。文字只需要运镜描述，不需要其他内容。`
5. **标题行格式**: `八帧 —— {短片标题} (总时长 X 秒)` (中文破折号). **标题永远写"八帧"**, 不改成"五帧" (网格固定 8 格)
6. **严禁 @故事板 自指**: 第一行严禁写 `@图片1作为故事板`. 参考图只列**角色**和**场景**, 道具也省
7. **故事板是"静止画面"原则, 允许"动作高潮瞬间" frozen frame** (见 §4.3)
8. **镜头不足 8 时用"黑屏" 补足 (v1.23)** — 故事板网格固定 8 格, 实际有内容镜头 < 8 时, 用 `镜头N | 黑屏` 补足到 8. **不是"第 8 镜永远是黑屏"**, 是"不足 8 镜时把后面缺的补成黑屏"

   **规则**:
   - 实际 8 镜内容 → 8 镜全写内容, 不补黑屏
   - 实际 < 8 镜内容 → 后面缺的镜头都写"黑屏" 补到 8

   **例 1 (实际 5 镜)**:
   ```
   镜头1-5 全写内容
   镜头6 | 黑屏
   镜头7 | 黑屏
   镜头8 | 黑屏
   ```

   **例 2 (实际 3 镜)**:
   ```
   镜头1-3 全写内容
   镜头4 | 黑屏
   ...
   镜头8 | 黑屏
   ```

   **例 3 (实际 8 镜)**: 8 镜全写内容, 不补黑屏

   **Why**: GPT Image 看到段头"8 帧" 必须画 8 格. 不补 8 → 模型自己脑补补镜头 → 经常自加海报帧. "黑屏" 是最干净的"占位"。

   **配合 1:1 对应**: 视频 prompt **不需要补黑屏**, 只写故事板**有内容**的镜头数

## 4.3 frozen frame 原则

故事板每一帧是**一个静止画面 = 一张照片**, 但这个画面**可以是动作的高潮瞬间** (frozen frame), 不必规避动词。

### 判断标准

GPT Image 能不能从描述里画出**一张明确的画面**?

**❌ 禁用: 连续过程描述**:
- "戟从天空朝屋顶飞行直到接触" (过程)
- "鬼影从远处朝镜头逐渐飞来" (过程)

**✅ 允许: 动作高潮瞬间**:
- "神戟戟头**砸入**屋顶, 屋顶瓦片**飞溅**, 烟尘弥漫" (砸入瞬间)
- "鬼影**扑面**, 嘴几乎贴住镜头" (扑面瞬间)
- "童年主角**奔跑**, 半身倾斜跨步" (奔跑高潮姿态)

**思维**: 把每个镜头描述当成"摄影师按快门那一瞬抓到的画面"。

## 4.4 故事板动词允许 / 禁用对照

### 允许 (5 类)

| 类型 | 例 |
|---|---|
| **位置** | 在画面顶部 / 中央 / 右上 / 深处 |
| **朝向** | 凝视 / 面朝 / 背对 / 侧对 / 仰面 / 俯首 |
| **姿态 (静止)** | 悬挂 / 站立 / 跪坐 / 持刀 / 张口 / 闭眼 / 仰头 |
| **姿态 (动作高潮)** | 奔跑 / 扑面 / 砸入 / 撞击 / 飞溅 / 崩裂 / 塌陷 / 迸发 |
| **关系** | 围绕 / 包围 / 散落 / 堆积 / 紧贴 |

### 禁用 (过程动词)

朝镜头飞来 / 从远处坠下 / 缓缓走来 / 逐渐显形 / 朝 X 运动过去

### 区分"过程动词" 和"瞬间动词"

- **过程动词** (描述持续运动): 飞来 / 坠下 / 走来 / 显形 / 渗出 → **禁用**
- **瞬间动词** (描述某一刻的状态/动作): 砸入 / 飞溅 / 扑面 / 撞击 / 崩裂 / 跨步 / 张开 → **允许**

## 4.5 镜头演变 ≠ 拆多帧 (重要)

故事板每帧 = 一个**视觉锚点**。如果两个"镜头" 是**同一个镜头的镜头运动演变** (推/拉/横移/摇), 那它们是**视频阶段的一个镜头**, 故事板**只画一个锚点**。

### 判断: 推/拉/横移/摇 能否一次完成?

| 差异类型 | 镜头数 |
|---|---|
| 推镜头进 (远→近) | **1 镜** |
| 拉镜头出 (近→远) | **1 镜** |
| 横移摇 | **1 镜** |
| **切换不同主体/角度** | **2 镜** |
| **切换不同场景/位置** | **2 镜** |

### 错 ↔ 对 对照

❌ **错** (镜头运动演变拆成 2 帧):
```
镜头3 | 中近景 仰拍·静止 — 反派本体, 嘴张开露上下两排尖牙
镜头4 | 极端特写 平视·静止 — 镜头深入嘴内, 上下尖牙占满画面
```
→ 镜头4 = 镜头3 推镜头进嘴的演变, 视频阶段会自然处理。

✅ **对** (一帧故事板 + 视频 prompt 推镜头):
```
故事板镜头3 (唯一帧): 中近景 仰拍 — 反派本体, 嘴张开露尖牙

视频 prompt 镜头3 (对应): 中近景 仰拍·慢推 — 镜头从反派本体推进至嘴内深处
```

## 4.6 严禁自加"收尾/海报帧" 镜头 (重要)

故事板/视频 prompt 必须严格忠于:
1. **原 frame 范围**
2. **原 shotlist 范围**

**严禁自加**:
- "大远景拉远定格" 收束镜
- "多元素同框" 海报帧
- "鸟瞰全景" 收尾镜
- 任何**原素材没出现过的镜头**

**判断流程**:
1. 这一镜在**原 frame / 原 shotlist** 里吗?
2. 不在 → **删除**, 不要自加
3. 在 → 保留, 但要忠实于原视觉

**Why**: 死板教科书思维 ("每段必须海报帧收尾") 让 prompt 跟原素材脱节, 视频模型生成"自创收尾" 时可能跑偏。

## 4.7 故事板状态渐变需要新视觉锚点

状态渐变要分多镜, **但每镜必须有新视觉锚点 (景别/角度/主体/构图 至少一个不一样)**。

### 边界对照

❌ **错** (同景别+同角度+同主体, 只改细节状态):
```
镜头1 | 大远景 仰拍 — 古城屋顶 + 天空平整阴云
镜头2 | 大远景 仰拍 — 古城屋顶 + 天空翻卷浓云
```
→ 黑白线条故事板里, 两帧画出来 80% 像, 浪费格子。

✅ **对** (合并为一镜):
```
镜头1 | 大远景 仰拍 — 古城屋顶 + 天空翻卷浓云
```

### 3 问检查

1. 跟前一镜对比, 景别/角度/主体/构图至少一个不一样吗?
2. 黑白线条画出来, 跟前一镜能一眼区分吗?
3. 这一镜带来的新信息, 能不能在视频 prompt 阶段通过运动描述实现?

**3 个全"否" → 合并**。

## 4.8 故事板自检清单

- [ ] 第一行是不是 `@角色名`, 不是 `@故事板`?
- [ ] 镜头数对应原素材, 没自加海报帧?
- [ ] 段头/风格行/标题行三处固定文案有没有照搬?
- [ ] 道具有没有混进参考图清单 (应该省)?
- [ ] 每个镜头的动词是不是只在"位置/朝向/姿态/关系" 类?
- [ ] 有没有过程动词 (飞来/坠下/缓缓走/逐渐显形)? 有 = 错
- [ ] 推/拉/横移演变有没有拆成多帧?
- [ ] 同景别+同角度+同主体的相邻帧有没有合并?
- [ ] 过敏感词字典: redZone 拦截, 其他 zone 自动替换?
- [ ] 标题行带了总时长?
- [ ] 群像用自然量词, 不滥用"并排"?
- [ ] 方向词带"画面"前缀?

# §5 敏感词 4 区过滤字典

CineForge prompt 在发送给 LLM/GPT Image/视频模型前, **必须先过 4 区敏感词字典**。

## 5.1 redZone (红区, 无法替换需手动改后重试)

出现任何下列词, **立即拦截, 改剧本/分镜后重试**。

### 真人冒充类
真人照片, 本人上传, 换脸, Deepfake, 伪造身份, 模仿名人, 克隆声音, 还原本人, 真实人脸, 身份证照, 护照照片, 监控画面, 偷拍视角

### 政治人物
习近平, 李克强, 毛泽东, 邓小平, 江泽民, 胡锦涛

### 色情
色情, 裸体, 裸露, 性爱, 性交, 生殖器, 乳房, 臀部特写, 高潮, 性暗示, 诱惑姿势, 成人用品, AV, hentai, 恋童, 未成年人色情

### 血腥暴力
血腥, 断肢, 残骸, 大量出血, 杀戮, 自杀, 自残, 上吊, 酷刑, 虐待

### 恐怖主义
恐怖分子, 恐怖组织, 极端主义

### 死亡

## 5.5 过滤工作流

```
1. 写好剧本/分镜原文
   ↓
2. 跑 redZone 检测 — 命中任何词 → STOP, 改剧本/分镜后重写
   ↓
3. 跑 yellowZone 自动替换 (IP 名 → 品类词)
   ↓
4. 跑 celebrityZone 自动替换 (明星名 → 气质描述)
   ↓
5. 跑 ipZone 自动替换 (虚构 IP 角色 → 通用类型)
   ↓
6. 输出 prompt 给 LLM / GPT Image / 视频模型
```

## 5.6 敏感词替换时参考图标签必须同步

走完 redZone 替换后, **参考图标签 (`@图片N作为XXX`) 必须用替换后的词**。

❌ **错** (标签用原词, 正文用替换词):
```
@图片7作为吊死鬼群       ← 标签用 redZone 词
镜头1 | ... 干瘪人形群虚浮于背景  ← 正文用替换词
```

✅ **对**:
```
@图片7作为干瘪人形群     ← 标签同步替换
镜头1 | ... 干瘪人形群虚浮于背景  ← 正文一致
```

**操作**: redZone 过滤跑两遍 — 一遍跑正文, 一遍跑参考图标签清单。

# §6 工作流与参考图清单

## 6.1 工作流强制顺序

```
1. 出故事板 prompt (纯静态画面)
   ↓
2. 等用户确认 [通过] / [修改]
   ↓
3. 用户通过后, 出视频 prompt (含运动方向)
   ↓
4. 等用户确认 [通过] / [修改]
   ↓
5. 用户通过后, 进入下一个子单元
```

**严禁跳步**:
- ❌ 直接出视频 prompt (跳过故事板)
- ❌ 一次性出故事板 + 视频 prompt

**Why**: 故事板是低成本审稿环节, 用户在故事板阶段就能发现"构图错了/角色不对/道具漏了"等问题。

## 6.2 视频 prompt vs 故事板 prompt 参考图差异

| 模块 | 视频 prompt | 故事板 prompt |
|---|---|---|
| 参考图 | 故事板 + 角色 + 场景 + 道具 (7 张左右) | 角色 + 场景 (4 张左右), **不要故事板/道具图** |
| 首行 | `基于@图片1作为故事板` | `@图片N作为{角色名}` (严禁 @故事板) |
| 【创建声明】 | 有 | 无 |
| 【视觉风格】 | 有 (质感/色彩/特效/光线) | 无 |
| 镜头格式 | `镜头N | 景别+角度+运动 — 描述` + 音效行 | 同, 无音效行 |
| 风格行 | `电影级别的 CG {题材} 影片` | `分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注` |
| 【禁止项】+【强制声明】 | 有, 固定文案 | 无 |
| 标题行 | 无 | `八帧 —— {短片标题} (总时长 X 秒)` |

# §7 实战示例 (抽象化)

## 7.1 状态渐变拆多镜 (主角发现天象异变)

```
镜头4 | 全景 平视 — 童年主角【从画面右侧入画】, 旧屋-院子斑驳青砖白墙环绕, 天空染朱赭红
镜头5 | 近景 仰拍 — 童年主角仰头朝天, 嘴大张, 双手【向身侧自然垂落】, 脸部覆盖染朱赭红光
镜头6 | 近景 仰拍慢推 — 童年主角面部特写, 双眼【从泪水朦胧渐转惊愕凝固】凝视画面顶部
镜头7 | 远景 仰拍宽角度 — 旧屋-院子上空, 天空中央悬一黑色球体, 周围红光环冕【缓缓旋转】, 球体表面裂纹【从中心向外蔓延】
```

**状态渐变**: 镜头4-5 天空正常 → 镜头6 面部光蓝→红 (拐点) → 镜头7 日食正式显形

## 7.2 推镜头不拆多帧 (反派嘴部演化)

**故事板 (3 镜)**:
```
镜头1 | 远景 仰拍·静止 — 多颗反派从画面顶部朝中央方向围拢, 一群百姓挤于画面下方中央, 黑色烟雾弥漫
镜头2 | 特写 平视·静止 — 一颗反派的侧脸位于画面左边, 嘴张开占据画面中央, 嘴内含住一个中年男子的上半身
镜头3 | 中近景 仰拍·静止 — 画面中央区域, 一颗反派占据了整个画面三分之二, 嘴张开露上下两排尖利米黄色牙齿
```

**视频 prompt (3 镜, 镜头3 用推镜头)**:
```
镜头3 | 中近景 仰拍·慢推至极端特写 — 镜头从一颗反派本体推进至嘴内深处, 上下两排尖利米黄色尖牙渐近占满画面, 黑色嘴腔深处显现, 反派本体下方是燃烧的火光和逃跑的百姓们
```

应用规则:
- §4.5 推镜头不拆多帧 — 故事板镜头3 (嘴张开) → 推到嘴内 (尖牙特写) 是同一推镜头, 不拆 2 帧
- §2.3 不重复参考图外貌

# §8 完整骨架 (复制即用)

## 8.1 故事板 prompt 骨架

```
@图片1作为{角色A}
@图片2作为{角色B}
@图片3作为{场景A}
@图片4作为{场景B}

白色故事板。2×4 网格 8 帧黑白线条分镜，黑边框、红墨方向箭头、蓝色中文运镜批注。文字只需要运镜描述，不需要其他内容。

八帧 —— {短片标题} (总时长 X 秒)

镜头1 | {景别+角度+运动} — {画面描述 frozen frame}
镜头2 | {景别+角度+运动} — {画面描述 frozen frame}
...
镜头N | {景别+角度+运动} — {画面描述 frozen frame}

风格： 分镜故事板 —— 黑白线条、红墨方向箭头、蓝色中文运镜批注
```

## 8.2 视频 prompt 骨架

```
基于@图片1作为故事板
@图片2作为{角色A}
@图片3作为{角色B}
@图片4作为{场景A}
@图片5作为{场景B}
@图片6作为{道具A}

【创建声明】创建此短片 — 不包含任何移动箭头、路径线、镜头分割线

【视觉风格】
- 质感: 电影级 CG {题材}, {镜头焦段}, 自然胶片颗粒
- 色彩: {主色} ↔ {对比色} (必给对比对) + {辅助色}, 高对比, 黑位压暗
- 特效家族: {题材化物理特效, 例如黑雾流体 / 金属反光 / 火焰由内向外蔓延}
- 光线: {主光源} + {补光} + {特殊光效}

【镜头列表】(共 N 个镜头, 总时长 X 秒)
镜头1 | {景别+角度+运动} — {一句话紧凑动态, 含【运动方向】(必标 4 类才标), 严禁描述尾}
        音效: {环境低频} + {细节高频}
镜头2 | ...
        音效: ...
...
镜头N | ... (按原 frame/shotlist 真实视觉, 严禁自加海报帧)
        音效: ...

【风格】电影级别的 CG {题材} 影片

禁止项：文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】
无背景音乐，仅保留环境音与人声；画面禁字幕/文字/水印/Logo；禁止可读文字；禁止超现实夸张；禁止无反作用力动作
```
