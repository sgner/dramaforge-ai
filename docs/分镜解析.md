## §1 完整视听签名表 (8 字段锁定 · 所有镜头卡的底层约束)

> 必填全部 8 字段 · 大师基因 ≤ 3 位 (公式 A × B 或 A × B × C, A=骨架 60% / B=调色 30% / C=节奏 10%)。
> 自检: 大师不互斥 / 类型 = 配方一致 / 介质 vs 类型匹配 / 核心主题可视化 / 色彩 ID 覆盖完整 (≤ 6 个) / 不超过"什么都想要"。
> Reference: 详见 **附录 D · 视听签名规范库**

| 字段 | 锁定值 |
|---|---|
| 介质 (Medium) | [16mm / Super 16 / 35mm / 65mm / IMAX / Arri Alexa LF / Sony Venice / Red Komodo / 数字 + 胶片模拟 LUT] |
| 长宽比 (Aspect Ratio) | [1.33:1 / 1.85:1 / 2.39:1 / 2.76:1 / 1:1 / 9:16 / 可变比例] |

**8 字段自检清单**:
- [ ] 8 字段全部填写完整

- [ ] 色彩 ID ≤ 6 个 (角色/势力均覆盖, 没有漏色或重色)
- [ ] 类型 = 配方一致 (科幻怪兽不能用文艺片配方)

### 1. 视听签名 8 字段定义

#### Field 1 · 介质 (Medium)

记录什么决定看起来什么样. 数字 vs 胶片差别巨大, 大画幅 vs 35mm 也差别巨大.

| 介质 | 视觉指纹 |
|---|---|
| **16mm** | 颗粒粗 / 动态范围窄 / 带糙粒子感 |
| **Super 16** | 颗粒明显但更细 / 暖偏色 |
| **35mm** | 中颗粒 / 高动态范围 / 经典电影质感 |
| **65mm / IMAX** | 极高分辨率 / 极宽动态 / 几乎无颗粒 / 巨幕沉浸感 |
| **Arri Alexa LF** | 大画幅数字 / 极宽动态 / 浅景深奶油焦外 |
| **Sony Venice** | 大画幅 6K / 高对比 / 偏冷调 |
| **Red Komodo / V-Raptor** | 紧凑数字 / 锐利 / 偏数字感 |
| **IMAX 70mm** | 极致清晰 + 巨幕高度 / 颗粒可见但动态王 |
| **数字 + 胶片模拟 LUT** | 数字捕捉 + 后期叠胶片颗粒/光晕 |

**写法**: 主介质 + 必要时叠"模拟"层. 例: `Arri Alexa LF + 35mm 颗粒 LUT`.

#### Field 2 · 长宽比 (Aspect Ratio)

每个比例自带情绪暗示. 选错比例 = 类型错位.

| 比例 | 名称 |
|---|---|
| **1.33:1 (4:3)** | Academy / 复古电视 |
| **1.85:1** | 经典电影 |
| **2.39:1** | 宽银幕 / Scope |
| **2.76:1** | Ultra Panavision 70 |
| **1:1** | 方画幅 |
| **9:16 (竖屏)** | 短剧 / 抖音 / 快手 |
| **可变比例** | 切比例 |

**注意**: 9:16 不是 16:9 倒过来 = 同样的镜头. 9:16 强迫**人物占画面 70%**, 几乎不能用全景. 选 9:16 = 选了"贴脸戏"为主.

#### Field 3 · 调色基调 (Color Grading)

详细 13 款主流调色对照见本附录 §3 调色风格扩展库.

#### Field 4 · 色彩 ID (Color ID)

> 工业标准: 给每个主要角色/势力分配唯一色相. 这是"看一眼就知道谁是谁"的底层武器.

**写法**: `角色名 = 色相` 一行一个.

**示例 1 · 《拦截》(科幻怪兽机甲)**:
```
THETA (机甲)     = 工业琥珀
SENTINEL-07 (敌) = 警示红
军方             = 冷白 + 钢灰
平民             = 土褐
背景城市         = 工业青绿
```

**示例 2 · 《沙丘》**:
```
厄崔迪家族 = 海蓝 + 银
哈克南家族 = 黑 + 油绿
弗雷曼人   = 沙黄 + 蓝眼
帝国近卫   = 金红
```

**示例 3 · 张艺谋《英雄》**:
```
开篇黑白色块 (秦) = 黑
飞雪长空 (回忆 1) = 红
残剑赵姑娘 (回忆 2) = 蓝
真相段                = 白
最终段落              = 绿
```

**规则**:
- 每个主要角色/势力 1 个色相 (不能 2 个, 否则混淆)
- 总数 ≤ 6 (人眼区分极限)
- 反派色 vs 主角色必须对撞 (互补色或饱和度对撞)

#### Field 5 · 介质质感 (Texture)

记录"看上去脏不脏 / 闪不闪 / 雾不雾".

| 维度 | 选项 |
|---|---|
| **颗粒程度** | 无颗粒 / 微颗粒 / 中颗粒 / 重颗粒 |
| **光晕 (Halation)** | 无 / 微 / 明显光晕 (高光红边) |
| **反射** | 干净 / 偏炫光 / 重镜头眩光 (J.J. Abrams 式) |
| **大气元素** | 雾 / 雨 / 雪 / 灰尘 / 蒸汽 / 烟 / 砂尘 / 海雾 |
| **噪点** | 数字噪点 / 胶片颗粒 / 干净 |

**写法**: 选 3-5 个标签组合. 例: `中颗粒 + 雨水光晕 + 海雾 + 蒸汽`.

#### Field 6 · 核心主题 (Core Theme)

**一句话, 描述全片在视觉上想说什么**. 不是剧情, 是"视觉语言的中心论点".

写法: 主语 + 比喻动词 + 宾语. 一句话.

示例:
- 《拦截》: "人类文明的最后一次挥拳"
- 《银翼杀手 2049》: "造物主用泡沫和雾隐藏自己"
- 《沙丘》: "沙漠把人吞下后变成神"
- 《海街日记》: "时间像晾在阳台上的衣服, 慢慢被风吹干"
- 《奥本海默》: "原子里藏着两种火, 一种照亮人, 一种烧掉人"

**规则**: 不要写抽象哲学短语 ("救赎与希望"), 要写**画面**. 测试: 闭眼能否想象一帧画面? 不能 = 重写.

#### Field 7 · 大师基因 (Master DNA)

1-3 位导演 (不能 4 个以上, 多了稀释), 用 `A × B` 或 `A × B × C` 公式.

**公式说明**:
- A = 主视觉骨架来源 (60% 权重)
- B = 调色/质感来源 (30%)
- C = 节奏/剪辑来源 (10%, 可省)

**示例**:
- 《拦截》: 吉尔莫·德尔·托罗 × 迈克尔·贝 (机械哥特骨架 × 工业巨物尺度)
- 《XX 文艺》: 是枝裕和 × 罗杰·迪金斯 (家庭日常骨架 × 自然光质感)
- 《XX 武侠》: 王家卫 × 张艺谋 (霓虹浅景深 × 单色统治)
- 《XX 黑色片》: 维伦纽瓦 × 大卫·芬奇 (对称极简骨架 × 冷蓝精密)

**禁忌**:
- 错: 4+ 大师 = "什么都想要" = 拼贴感
- 错: 大师基因和类型不匹配 (如选诺兰拍乡土片)
- 错: 大师基因之间互斥 (如塔可夫斯基 × 迈克尔·贝, 慢和爆炸打架)

#### Field 8 · 类型片配方 (Genre Formula)

该类型在视觉上的标准动作: 开场怎么拍 / 转折怎么拍 / 高潮怎么拍.

详细库见 §4. 写法是一行简短动作清单.

**示例 · 《拦截》(科幻怪兽机甲)**:
```
开场: 巨物剪影从地平线缓推 (尺度震慑)
转折: 第一次正面接触, 低角度 360° 仰拍机甲 (英雄诞生瞬间)
高潮: 海上对决, 慢动作爆破 + 尺度对比镜头 + 重 VFX
落幕: 残骸俯瞰大全景 + 静音几秒
```

- **视觉特征**: 纵深构图 (前景遮挡 + 中景人 + 后景奇观); 伦勃朗光 (chiaroscuro, 单光源 + 大面积阴影)
- **借鉴时机**: 黑暗童话 / 怪物科幻 / 哥特恐怖.


#### 迈克尔·贝 (Michael Bay)

- **视觉特征**: 低角度仰拍 ("英雄镜头", 让人物 = 神); 360° 旋转环绕 + 主角站立
- **借鉴时机**: 大场面动作 / 军事 / 巨物 / 爆破密集.

### 4. 类型片视觉惯例库

#### 科幻怪兽机甲 (PacRim / Real Steel / Godzilla 路数)
- **视觉工具**: 工业写实 (机甲不光滑, 有铆钉/锈迹/油污) + 巨物尺度 (镜头从下往上 + 人物/汽车/楼对比) + 蓝橙对撞 + 重 VFX + 雨/海雾大气
- **开场**: 远景 + 巨物剪影逐渐显现 (尺度震慑)
- **落幕**: 残骸俯瞰大全景 + 静音几秒

#### 武侠诗意 (徐克 / 张艺谋 / 王家卫)
- **视觉工具**: 慢动作 + 飘逸服饰 + 自然元素 (花瓣/竹叶/雪/水) + 单色统治 + 大全景留白
- **开场**: 静景大全景 (山/竹林/雪) + 主角入画
- **落幕**: 大全景中两人渐行渐远

#### 文艺片 (Slow Cinema / Art House)
- **视觉工具**: 长镜头 + 中景 + 自然光 + 极少配乐 + 横构图 + 留白
- **开场**: 一个长镜头 (3-5 分钟), 无台词或极少
- **落幕**: 空镜 / 风景 / 时间流过

#### 短剧 (中国微短剧 9:16)
- **视觉工具**: 9:16 竖屏 + 高饱和 (饱和度比电影 +30%) + 快切 (1-2 秒/镜) + 大特写堆叠 (人脸占画面 70%) + 小景别为主 (中景/近景/特写, 不用全景) + 模糊背景 (浅景深贴脸) + 反转节拍密集
- **开场**: 大特写直接抓眼 (角色甩巴掌 / 怒吼 / 哭) + 字幕
- **落幕**: 留悬念特写 + 滑动到下一集

**短剧硬约束**:
- 全景几乎不用 (浪费像素)
- 演员表情 ≥ 镜头质感 (观众看的是脸)
- 1 集 ≤ 90 秒 = 镜头数 ≥ 60 个
- 大特写堆叠是合规, 不是缺点

### 7. 常见错误 (Don'ts)

1. 错: **"我什么都喜欢"** = 拼贴 = 无签名. 必须砍到 1-3 位大师

# 附录 G · 单元结构规范 (来自 SKILL references/unit-segmentation.md)

> §2 单元结构的 Frank Daniel 8-Sequence 标准 / motif 锚点中文库 / 单元过渡 3 策略 / 短中长片单元数适配表.

## Unit Segmentation · 单元化分段 (第 3 步)

> 把已锁定视听签名的剧本切成 5-10 个**戏剧节拍单元** (Sequence) — 每个单元 = 一部完整 mini-movie · 是镜头卡拆解 (第 4 步) 的容器.

---

### 全局禁用 emoji (v1.6 audit-5 起强制)

**用户硬性约束**: 单元结构表 / 任何输出**不得使用 emoji 或表情符号**.

下文规则已按此约束整理: 单元结构表去掉 emoji 列, 仅保留: # / 标题 / 时长 / 节奏 / 戏剧任务 / 视觉 motif / 钩子.

替代策略: 视觉 motif 列用**中文短语** (如 "残骸火海" / "母舰阴影") 表达视觉锚点. 单元间气氛对比通过**节奏列** (紧/中/松 + 轻/中/重) 表达, 不靠 emoji.

---

### 1. 理论基础 · Frank Daniel Sequence Approach

#### 1.3 Frank Daniel 的 8 个 Sequence (蒸馏自 Gulino)

| # | 幕 | 名称 | 戏剧任务 | 长度% |
|---|---|---|---|---|
| **S1** | Act 1 | **Status Quo + Hook** | 开场画面 / 钩子 / 主角常态世界 / exposition / 在结尾或前奏出现 inciting incident | 12.5% |
| **S2** | Act 1 | **Predicament + Lock-In** | 主角试图恢复正常但失败, 形势更糟. 锁定主角"想要什么 (want)" + 抛出**核心戏剧问题 (central dramatic question)** | 12.5% |
| **S3** | Act 2A | **First Obstacle + First Try** | 主角第一次主动出击解决核心问题, 引入副线 (subplot), 通常包含第一个大场面 set piece. 失败 | 12.5% |
| **S4** | Act 2A | **First Culmination / Midpoint** | 第二次尝试, 推到全片中点. 大反转 / 大揭秘 / 关系翻面, 提升 stakes, 为下半场铺垫 | 12.5% |
| **S5** | Act 2B | **Subplot + Rising Action** | 中点余波. 新角色或新机会涌入, 主角的 need (内在) 与 want (外在) 开始撕裂. 副线高度活跃 | 12.5% |
| **S6** | Act 2B | **Main Tension Climax + Dark Night** | 简单方案耗尽, 主角必须直面核心问题. **主线 tension 顶峰** + 经典"灵魂黑夜" (dark night of the soul) | 12.5% |
| **S7** | Act 3 | **Resolution Attempt + Twist** | 看似要解决了, 但 stakes 再升一档 / 出现假结局 / final twist. 强迫终局 | 12.5% |
| **S8** | Act 3 | **Final Resolution + Echo** | 全部 tension 收束. 副线收尾. 结尾画面常**回响开场画面** (visual echo) | 12.5% |

#### 1.4 Tension 的链式传递

每个 sequence **结尾抛出一个尚未回答的问题**, 强迫观众继续往下看:

- S1 结尾: "主角能不能维持常态?"  → S2 回答"不能" + 新问题 "他要去哪?"
- S2 结尾: "他能搞定 X 吗?"  → S3 回答"不能" + 新问题"那 Y 呢?"
- ... 一直链到 S8

> 实操要点: **每个单元的钩子 (hook) 必须是下一单元的 setup**. 这是单元化分段比传统三幕表更细的地方.

---

### 2. 短/中/长片单元数适配

Frank Daniel 8 个是长片的标准, 短片需要按比例压缩. 单元数取决于全片时长:

| 全片时长 | 推荐单元数 | 单元平均时长 | 用途 / 简化策略 |
|---|---|---|---|
| **30-90 秒** (短剧单集 / TVC / 病毒视频) | **2-3 个** | 15-30 秒 | 极简: setup → twist → button. 跳过中段, 钩子即结局 |
| **1-3 分钟** (概念短片 / what-if / 预告片) | **3-5 个** | 30-60 秒 | 一镜到底简化版: hook / inciting / midpoint twist / climax / coda |
| **5-10 分钟** (叙事短片 / 微电影) | **4-6 个** | 1-2 分钟 | 紧凑节拍, 三幕但每幕只 1-2 个 sequence. 可省 dark night |
| **30-60 分钟** (剧集单集 / 网大单集) | **5-7 个** | 5-10 分钟 | 简化版 8-sequence: 合并 S1+S2 为 cold open + setup, 合并 S5+S6 为危机段 |
| **90-120 分钟** (长片) | **8 个** | 12-15 分钟 | 标准 Frank Daniel 完整 8 段 |
| **120 分钟+** (史诗长片) | **9-12 个** | 12-15 分钟 | 在中段加 sub-sequence, 总长度不破 15 分钟/段否则节奏垮 |

**经验值**: 单元数太少 (< 推荐区间) 节奏散; 太多 (> 推荐区间) 镜头卡阶段会过载, 失去结构感.

---

### 3. 单元 4 要素 (核心格式)

#### 3.1 必填 3 项 (旧版的"Emoji 标识"已废止)

| 要素 | 说明 | 示例 |
|---|---|---|
| **标题** | 3-7 字中文短语, 用 `·` 或 `/` 分隔关键意象 | 海面对撞 |
| **时长** | xx 秒 / xx 分 | 25" |
| **戏剧任务** | 单元结束时观众应该知道/感受到什么 | 双方机甲在水面短兵相接, 主角首次见血 |

#### 3.2 推荐补充 4 项

| 要素 | 说明 | 示例 |
|---|---|---|
| **节奏基调** | 情节松紧 + 情感轻重 (松/中/紧 + 轻/中/重) | 紧/重 |
| **核心戏剧动作** | 目标 → 阻碍 → 结果 (3 段式) | 锁定敌人 → 海浪干扰 → 失手 |
| **视觉 motif** | 本单元视觉锚点 (从第 2 步视听签名挑) | 浪花溅琥珀光 / 红色 HUD |
| **承接钩子** | 本单元结尾递交什么悬念给下一单元 | "EJECT 按钮亮起" (S5 才会用) |

> 钩子要求**对仗下一单元的 setup**. 钩子写完, 立刻去下一单元的戏剧任务里找呼应; 找不到 → 钩子无效 → 重写.

---

### 4. 视觉 motif 锚点 (中文短语库 · 替代旧 emoji 库)

**已废止旧 emoji 库**. 用**中文短语**做视觉锚点, 直接放在"视觉 motif"列即可, 不再有单独的"emoji"列.

锚点选词原则:
- **3-6 字**, 优先名词短语
- **画面具象** (能直接拍, 不写抽象情绪)
- **本单元独有** (跨单元重复 = 段落镜像, 是刻意手法不是冗余)

按类型可选词参考 (不强制使用):

| 类别 | 中文短语示例 |
|---|---|
| 环境 / 空间 | 都市霓虹, 海面浪涌, 高塔剪影, 废墟弃楼, 古堡王宫, 隧道地下, 桥梁跨海, 窗框中景, 卧室私密 |
| 情绪 / 状态 | 心碎失去, 烈焰失控, 流血创伤, 喘息边缘, 死亡威胁, 惊恐见鬼, 寒冷麻木, 抑郁哀伤, 迷茫隔离, 至暗时刻 |
| 戏剧动作 | 开场序幕, 揭秘真相, 转折双面, 陷阱设局, 对决武戏, 锁定目标, 高潮顶峰, 突破解锁, 黎明新生, 爆破大事件, 倒计时压力 |
| 人物 | 主角独戏, 群像多线, 权力反派, 童弱小者, 联手结盟, 别离告别, 爱情核心, 心智推理 |
| 物件 / 抽象 | 宝物钥匙, 通讯远程, 屏幕媒介, 信号联络, 仪式守夜, 闪电冲击, 不可抗力, 命运母题, 透视揭示 |

> 同片单元间锚点不重复 (除非刻意做"段落镜像", 例 S1 与 S8 都用"黎明新生"表示 echo).

---

### 5. 单元过渡设计 · 3 种对比策略

单元 N 结尾 → 单元 N+1 开头 **必须有至少 1 种对比**. 没对比 = 节奏粘连 = 观众疲劳.

#### 5.1 情绪对比

紧张 → 静默 / 喜剧 → 悲剧 / 高亢 → 低落.

#### 5.2 视觉对比

暗 → 亮 / 拥挤 → 空旷 / 暖 → 冷 / 紧 → 宽 / 实景 → 抽象.

#### 5.3 节奏对比

快切 → 长镜头 / 大动作 → 微表情 / 多线并剪 → 单点凝视.

> **铁律**: 相邻单元至少 1 种对比. 高潮单元 (S6 / S7 长片版) 后必接静默单元 (情绪对比), 给观众喘息.

---

### 6. 工作流 (7 步)

```
1. 读完整剧本 + 第 1 步场景列表 + 第 2 步视听签名
   ↓
2. 找"自然切口" — 列出所有候选切点
   候选: 时空跳跃 / 主角情绪转向 / 力量平衡反转 / 主题揭示 / 视觉 motif 切换
   ↓
3. 按时长档位选 N (见 §2 表), 在候选切点中选出 N-1 个
   ↓
4. 给每个单元起标题 (3-7 字 · 关键意象 · 用 · 或 / 分隔)
   ↓
5. 标 4 必填 + 4 推荐要素 (时长 / 戏剧任务 / 节奏 / 钩子 / motif)
   ↓
6. 检查相邻单元过渡 — 至少 1 种对比, 没有就调整切点或重写钩子
   ↓
7. 输出单元结构表 (markdown · 见 §7)
```

#### 关键判断点

- **切点不是场景边界**: 一个单元可包含多个场景; 一个长场景也可被切成两个单元 (例 *《现代启示录》* Kurtz 营地戏被切 3 个单元)
- **单元≠幕**: 8 个 sequence 跨 3 幕分布. 不要把单元数硬塞进 3 段
- **高潮必须在 70-85% 处**: 长片 S6 末或 S7 内; 短片倒数第二个单元

标准 markdown 表见主体 **Part 2 §2 单元结构** · 完整 INTERCEPT 7 单元填好范本见 **附录 Z · Part 2 §2**.

### 9. 常见坑

| 症状 | 原因 | 修法 |
|---|---|---|
| 单元 4-5 像同一段戏 | 中段被合并, 缺 midpoint reversal | 拆出"中点反转" — 关系翻面 / 大揭秘 |
| 高潮单元放在最末 | 没留 resolution / coda | 把最末单元前移高潮, 加一个 13-30" 的 echo 单元 |
| 钩子全是 "...然后..." | 钩子写成场景描述而非问题 | 钩子改成"开放问题 / 视觉省略号" |
| 节奏全是 "紧/重" | 没安排呼吸单元 | 在高潮前后插一个"松/轻"或"松/中"单元 |
| 单元过多 (10+ for 短片) | 把场景表抄成单元表 | 多个场景合并为一个戏剧任务的单元 |
| 单元过少 (3 for 长片) | 把幕直接当单元 | 每幕至少 2-3 sequence, 区分 setup / culmination |

# 附录 H · 镜头卡格式规范 (来自 SKILL references/shot-card-format.md)

> §3 镜头表的 7 列严格定义 / 机位库 10+ / 运镜库 12+ / 转场库 10+ / 高级镜头技法 16+ / 中文景别 7 档 / ASL 类型片基准表 / 12 项自检.

## 镜头卡格式 · Shot Card Format Reference

> **第 4 步专用 reference**. 输入第 3 步单元结构 (5-10 个 sequence), 输出每单元 5-12 个镜头的工业级镜头表. 本文件是 SKILL `shotlist` 的核心格式定义和素材库.

---

### 0 · 总览 · 7 列标准

```
| # | 时间 | 时长 | 景别 | 机位·运动 | 内容 | 声音 |
```

每个镜头一行, 7 列全部强制填写. 这是工业级 shot list 的最简但够用的列结构 (StudioBinder/Frame.io 模板的精炼版).

#### 列定义速查

| 列名 | 强制 | 说明 | 示例 |
|---|---|---|---|
| **#** | 必填 | 镜号 (01, 02, ...). 可加中文标签 | `02 [海报帧]` / `15 [伏笔]` / `08 [关键]` |
| **时间** | 必填 | 起始时间码 (从 0:00 算, mm:ss 或 h:mm:ss) | `0:00` / `0:42` / `1:23` |
| **时长** | 必填 | 秒数, `1"` / `2.5"` / `8"` 默认 1-8 秒 | `2"` / `3.5"` |
| **景别** | 必填 | 7 档中文 (极端特写/近景/中近景/中景/中远景/全景/远景) 或 `—` (黑屏/特殊) | `极端特写` / `中景` / `全景` |
| **机位·运动** | 必填 | "机位 · 运动方式 (· 速度修饰)" | `低角度·横移` / `水下·向上仰角` |
| **内容** | 必填 | ≤30 字, 主体+动作+关键细节, 视觉化, 可直接拍 | `琥珀瞳孔在黑暗中睁开·收缩时荧光变浓` |
| **声音** | 必填 | 关键声音元素 + 对白 (即使"无声"也写) | `次声波低鸣+气泡` / `静默 2"后心跳骤响` |

---

### 1 · 镜号 (#) 与 Emoji 标记系统

#### 镜号规则

- 从 `01` 开始, 按拍摄/剪辑顺序连续编号
- 单元结尾不重置, 全片连续
- 三位数 `001-999` 仅长片用; 短片 `01-99` 已够

#### 中文标签 (工业实践)

| 标签 | 含义 | 用途 | 全片配额 |
|---|---|---|---|
| `[海报帧]` | 海报帧 / Poster Frame | 适合做主视觉/营销物料的镜头 (单帧美) | 5-9 个 |
| `[伏笔]` | 伏笔 / Foreshadow / Hook | 后面要回扣的种子 (物件/动作/视觉) | 必有回扣 |
| `[关键]` | 关键叙事点 / Key Story Beat | 主线进展的关键转折 | 3-7 个 |
| `[重特效]` | VFX 重镜 / Heavy VFX | 后期工时大 (粒子/合成/CG) | 按预算 |
| `[长镜]` | 长镜头 / Long Take | 8 秒+, 一镜到底 | 稀少 |
| `[音锚]` | 声音锚点 / Sound Anchor | 配乐切换/静默点 | 单元间 |
| `[特设备]` | 机械镜头 / Mechanical | 需特殊设备 (摇臂/斯坦尼康/水下/无人机) | 按预算 |

**多标签叠加**: `02 [海报帧][关键]` (既是海报帧又是叙事点). 但同一镜不超过 2 个.

---

### 2 · 时间与时长

#### 时间码格式

- 短片 (≤3 分钟): `mm:ss` (如 `2:14`)
- 长片: `h:mm:ss` (如 `1:23:45`)
- 起始时间 = 上一镜的起始 + 上一镜的时长
- 全片首镜固定 `0:00`

#### 时长颗粒度

- 整数秒: `1"` `2"` `3"`
- 半秒精度 (短片刚需): `1.5"` `2.5"` `3.5"`
- 闪剪/Flash: `0.3"` `0.5"` (≤1 秒, 必标 Flash Cut)
- 长镜头: `8"+` 标记 `[长镜]`

#### ASL (Average Shot Length) 自检

时长累加 = 单元时长 (单元结尾) = 全片时长 (整片结尾). 误差 ±5% 内.

---

### 3 · 景别 7 档

中文 7 档, **以"画面填充人体什么部位"定义**:

| 景别 | 范围 | 主要用途 | 经典片例 |
|---|---|---|---|
| **极端特写** | 眼睛 / 嘴唇 / 单一指尖 / 一颗钉 | 情感顶点 / 关键细节 / 抽象符号 | 《镖客三部曲》(Sergio Leone) 眼睛对决; 《黑天鹅》羽毛长出皮肤 |
| **近景** | 头部 (下巴到发际, 略含肩) | 表情 / 内心独白 / 情绪 | 《沉默的羔羊》Hannibal 直视镜头; 《公民凯恩》"玫瑰花蕾" |
| **中近景** | 胸部以上 | 对白主力 / 半身肢体 + 表情 | 《老无所依》对峙长镜; 电视剧默认对白 |
| **中景** | 腰部以上 | 动作 + 表情 / 双人对话 | 《教父》会议桌默认; "两人中景" 是行业基线 |
| **中远景** | 大腿以上 (含牛仔镜) | 动作 + 环境关系 / 武打编排 | 西部片配枪带; 《神奇女侠》战场 |
| **全景** | 全身 + 部分环境 | 空间关系 / 群体调度 | 《阿拉伯的劳伦斯》骆驼远眺; 《辛德勒的名单》红衣女孩 |
| **远景** | 全身渺小 + 大量环境 | 建立 / 史诗感 / 终幕渺小 | 《疯狂麦克斯·狂暴之路》沙漠车队; 《2001》猿人遥望 |

#### 景别选择速查

- **情感顶点** → 极端特写 (眼/泪/手) 或 近景 (脸)
- **对白** → 中近景 或 中景 (单/双人)
- **动作戏** → 中远景 (看招式) + 中景 (反应) 交替
- **建立空间** → 全景 或 远景 (开场/转场)
- **群体戏** → 全景 (站位看清) + 中景 (个人反应)
- **特殊**: `—` 用于黑屏 / 闪剪 / 纯字幕 / 抽象图形

---

### 4 · 机位库 (10+)

机位 = 摄影机相对主体的**空间位置和角度**. 与"运动"分开 (运动是怎么移动). 写法: `<机位修饰>·<运动>`.

| 中文 | 适用场景 |
|---|---|
| **平视** | 默认对白 / 自然主义 |
| **俯拍** | 角色失败 / 上帝视角暗示 |
| **仰拍** | 反派登场 / 英雄定格 |
| **荷兰角 (倾斜)** | 惊悚 / 反派内心 / 醉酒 |
| **主观视角** | 第一人称恐惧 / 跟踪 |
| **过肩** | 双人对白 (反打 OTS 经典) |
| **上帝视角** | 建立 / 终幕 / 群体调度 |
| **虫视角** | 巨物 VFX / 仰望英雄 |
| **侧面剖视** | 武打对峙 / 决战 |
| **双人构图** | 对白 / 关系定调 |
| **三人构图** | 谈判 / 三角恋 |

#### 复合机位写法

- `低角度 OTS·过肩` = 低角度 + 过肩复合
- `俯拍 POV·主观` = 上方俯视的 POV (如阳台往下看)
- `荷兰角 极端特写·倾斜` = 倾斜的极端特写

---

### 5 · 运镜库 (12+)

运动 = 摄影机**怎么移动**. 与机位 (在哪) 正交. **写法**: `<机位>·<运动>(·<速度修饰>)`.

| 中文 | 适用场景 |
|---|---|
| **摇** | 横向跟随 / 环境扫描 |
| **仰俯** | 高楼向上扫 / 人物从脚到头建立 |
| **推** | 情绪逼近 / 心理紧绷 |
| **拉** | 情绪释放 / 揭示更大场景 |
| **横移** | 跟拍走路 / 平视环境横扫 |
| **升降** | 角色站起/坐下平视跟随 |
| **摇臂** | 开场建立 / 终幕拉起 |
| **斯坦尼康** | 长镜头跟随 / 伪一镜到底 |
| **手持** | 战争/纪录片风 / 心理失控 |
| **跟拍** | 角色行走 / 追逐戏 |
| **推拉变焦** | 风格化推进 |
| **急摇** | 转场利器 / 场景切换 |
| **无人机** | 建立 / 史诗 / 自然 |
| **高速摄影** | 爆炸瞬间 / 子弹时间 |
| **静止** | 冷峻凝视 / 留白思考 |

#### 速度修饰

- `慢推` / `急推` (推进速度)
- `丝滑横移` (Steadicam 跟拍标配)
- `急摇接切` (Whip Pan + Cut, 隐藏剪辑)
- `Flash Cut` (≤1 秒, 闪剪)

---

### 6 · 转场库 (10+)

转场 = 镜头与镜头之间的连接方式. 默认 `Hard Cut`, 不写默认即可; 特殊转场写在镜末或镜首注释.

| 中文 | 用法 |
|---|---|
| **硬切** | 默认转场, 直接切换 |
| **匹配剪辑** | 形/动/声匹配, 上下镜共享视觉元素 |
| **撞切** | 强烈反差 (静→噪 / 安宁→暴力 / 笑→哭) |
| **J 切** | 下场声音先入 (画面晚于声音) |
| **L 切** | 上场声音后留 (画面切了声音继续) |
| **交叉剪辑** | 双线并行 (A 线 / B 线交替) |
| **跳切** | 同景别小幅时间跳跃 (戈达尔签名) |
| **叠化** | 时间流逝 / 梦境过渡 |
| **淡入** | 章节起始 / 黑屏渐显 |
| **淡出** | 章节结束 / 渐黑 |
| **圈入圈出** | 复古 / 注意力锁定 |
| **划像** | 风格化转场 (条状/星形/对角) |
| **急摇接切** | 急摇 → 隐藏剪辑 → 下镜 |
| **闪白/闪黑** | 单帧白/黑 → 撞击 / 闪回触发 |

---

### 7 · 高级镜头技法 (12+)

镜头本身的设计模式 (复合手法 / 风格签名), 不是单纯机位/运动. 用于在镜头卡 "内容" 列标注.

| 名称 | 描述 |
|---|---|
| **一镜到底** | 极长不剪, 8 秒+ 到 10 分钟+ |
| **变焦对焦切换** | 焦点从前景切到背景 (或反向) |
| **动作匹配剪** | 上镜动作 → 下镜不同景别接续动作 |
| **镜面反射** | 镜中倒影同框 / 镜中真相 |
| **插入镜头** | 突然切到道具/手部/细节特写 |
| **闪剪** | 跳到无关画面 (心理 / 联想 / 幽默) |
| **反应镜头** | 切到旁观者反应 (对白后必有) |
| **子弹时间** | 多机位环绕 + 时间冻结/慢放 |

### 10 · 第 4 步工作流 (拆镜步骤)

```
第 3 步单元结构 (5-10 个 sequence) ← 输入
        ↓
   ┌─ 单元 1 拆 5-12 镜 (按视听签名 + 钩子分配景别/运动)
   │
   ├─ 单元 2 拆 5-12 镜 (前一单元结尾 → 本单元开头要无缝)
   │
   ├─ ... (每单元独立拆解)
   │
   └─ 最后单元 (含尾钩 / 收束)
        ↓
   全片镜头表 (markdown table) ← 输出
```

#### 标准步骤

1. **加载第 3 步单元结构**: 读取 5-10 个 sequence 的时间段 / 视听签名 / 钩子
2. **逐单元拆解**: 每单元 5-12 个镜头 (短单元 5-8, 长单元 8-12)
3. **每镜填 7 列**: # / 时间 / 时长 / 景别 / 机位·运动 / 内容 / 声音
4. (后续步骤见 100% 完整源版)

#### 单元内景别分配模板 (5-12 镜)

- **首镜**: 远景 / 全景 (建立 Establishing Shot) 或 极端特写 (强钩子 cold open)
- **中段**: 中景 / 中近景 主体 + 极端特写/近景 情感顶点 + 全景/中远景 调度变化
- **末镜**: 钩子镜 (Match Cut / 急摇 / 撞切 / 黑屏闪剪)

#### 单元间衔接 5 法

1. **Match Cut**: 物件/形状/动作匹配 (如圆形 → 圆形)
2. **J-Cut**: 下单元声音先入 (常用)
3. **L-Cut**: 上单元声音延留 (情绪滞留)
4. **物件回扣**: 上单元出现的物件在下单元再现 (伏笔 [伏笔])
5. **撞切 Smash Cut**: 静→噪 / 慢→快 / 黑→白

### 12 · 常见错误与修正

| 错误 | 修正 |
|---|---|
| 错: 全程 中近景 + 平视 | 对: 加入 极端特写 情感顶点 + 全景 空间建立, 景别多样 |
| 错: "内容" 列写"主角很愤怒" | 对: "主角左拳砸桌·茶杯震飞·茶水溅" (视觉化) |
| 错: "声音" 列空白 | 对: 写"静默 2"" / "环境底噪" / "心跳渐响" |
| 错: 时长写 "1 秒" / "1s" | 对: 统一 `1"` |
| 错: 单元结尾硬切到下单元 | 对: 设计 Match Cut / J-Cut / 急摇 承接 |
| 错: 景别用工业缩写 (ECU/MS/ELS) | 对: 用中文 7 档 (极端特写/中景/远景), 严禁英文缩写 |

| 错: 一个单元 20+ 个镜头 | 对: 拆分为两个子单元 (大单元 = 长片节奏) |
| 错: 极端特写 拍单一道具但没在后镜回扣 | 对: 标 [伏笔] 并确保 2-3 单元后有 Match Cut 回扣 |

### 1. ASL · Average Shot Length 概念

#### 1.1 定义

**ASL = 全片有效时长 / 总镜头数** (单位: 秒)



#### 1.2 节奏的统计学意义

- **ASL 短** = 切得碎 = 节奏快 / 紧迫 / 密度高 (但易疲劳)
- **ASL 长** = 切得少 = 节奏慢 / 沉浸 / 表演空间大 (但易拖沓)
- **σ (标准差) 大** = 节奏起伏大 (有快有慢, 戏剧张力强)
- **σ 小** = 节奏单调 (要么全快要么全慢)

工业判断: **看 ASL 也要看 σ**. 一部好的商业片通常 ASL 在 2-4 秒, 但 σ 也得有 — 高潮快慢交替才有呼吸.

---

### 2. 类型片 ASL 基准 (Cinemetrics 数据库蒸馏)

| 类型 / 时代 | ASL 范围 | 代表作 / 出处 |
|---|---|---|
| 默片 (1910s-20s) | 5-8 秒 | 早期 Griffith / Eisenstein |
| 经典好莱坞 (1930s-50s) | 8-11 秒 | 黑色电影 / 类型片黄金期 |
| 1960s-80s 过渡期 | 6-10 秒 | 新好莱坞作者电影 |
| 现代商业大片 (1990s-2000s) | 4-6 秒 | 漫威主流 / 好莱坞 A 级 |
| 当代动作 / 高密度剪辑 | 1.5-2.5 秒 | *Quantum of Solace* 1.85" / 迈克尔贝 / 速激 |
| 短剧 / 短视频 (国内) | 1-2 秒 | 抖音/快手竖屏短剧 |
| 预告片 (Trailer) | 1-1.5 秒 | 商业大片 trailer money cut |
| 文艺长镜头主导 | 15-60 秒 | 蔡明亮 / 锡兰 / 阿彼察邦 |
| 极致长镜头 | 60+ 秒 | Tarkovsky 《潜行者》ASL 68 秒 (142 镜 / 163 分钟) |
| 单镜电影 | 全片 1 镜 | 《俄罗斯方舟》96 分钟 1 镜 |



#### 2.1 ASL 异常诊断红线

| 现象 | 风险 | 处理建议 |
|---|---|---|
| ASL < 1.5s 且非动作高潮 | 视觉疲劳 / 信息过载 | 适度合并 / 用长镜留白 |
| ASL > 8s 且非文艺片 | 节奏拖沓 / 商业不够 | 加机位变化 / 切碎覆盖 |
| 单段 ASL 与全片差异 > 50% | 该段节奏偏离 | 确认是有意 (高潮/留白) 还是漏 |
| σ < 全片 ASL 的 30% | 节奏过于均匀 | 加快慢对比 / 制造呼吸 |
| 连续 ≥ 3 段同节奏 | 观众适应=不再感动 | 中插一段对比节奏 |

### 4. VFX 分级 S/A/B/C · 量化标准

#### 4.1 工业现状

国际大厂 (ILM / WETA / Pixomondo / MPC / DNEG) 都用 **shot complexity tier** 内部分级, 但每家叫法不一: ILM 叫 Tier 1-4, WETA 叫 Hero/Heavy/Medium/Light, Pixomondo 用 Complexity Score 1-10. 业界 bidding tool (如 Filmustage / ActionVFX) 普遍采用 **4 档制**: 按 CG 占比 / 数字资产数 / 合成层数 量化.

#### 4.2 标准 4 档定义 (本 SKILL 采用)

| 等级 | 工业别名 | CG 占比 | 数字资产 | 合成层 | 工时倍率* | 占比 |
|---|---|---|---|---|---|---|
| **S** | Hero / Tier-1 | ≥ 90% | 主角级 CG (角色/巨物/全景) | 8+ 层 | **80x** | 5-15% 镜头, **吃 60-80% 预算** |
| **A** | Heavy / Tier-2 | 50-90% | CG 主体 + 实拍背景 (或反之) | 4-7 层 | **15x** | 15-25% 镜头, 占 20-30% 预算 |
| **B** | Medium / Tier-3 | 20-50% | 局部修补/扩展/小特效 | 2-3 层 | **4x** | 30-40% 镜头, 占 8-12% 预算 |
| **C** | Light / Tier-4 | < 20% | 调色/小修补/光线/穿帮去除 | 1 层 | **1x** | 30-50% 镜头, 占 2-5% 预算 |

\* 工时倍率: 以 C 级一个镜头为 1 单位, S 级单镜约 80 倍工时. 数据蒸馏自 fxguide / VFX Voice / Filmustage 公开 bidding 案例 + ILM/WETA 项目复盘 (e.g. 《阿凡达 2》ILM 48 个 one-off 镜头复盘).

#### 4.3 判断标准 · 实操问答

每个镜头按顺序问 4 个问题:

1. **有没有完全 CG 的主体?** (CG 角色 / CG 巨物 / 全 CG 环境)
   - 是 → 至少 A 级, 看占比再判 S
2. **CG 占比超过 50%?**
   - 是 → A 级
3. **有没有合成 / 修补 / 扩展?**
   - 是 → 至少 B 级
4. **有调色 / 小补丁?**
   - 是 → C 级
   - 否 → 无 VFX (Practical only)

### 9. 镜头优先级管理 · 制片视角

VFX 等级直接对应**预算 + 排期 + 分包策略**:

| 等级 | Previs/Techvis | 拍摄 | 后期工时 | 预算占比 | 分包建议 |
|---|---|---|---|---|---|
| **S** | 必须 (1-2 个月 previs + techvis) | 优先排, on-set VFX sup 在场 | 6-12 个月 | 50-65% | Tier-1 大厂 (ILM/WETA/MORE) 独家 |
| **A** | 重点段做 previs | on-set VFX sup 关注 | 3-6 个月 | 25-30% | Tier-1/2 大厂分包 |
| **B** | 不必 previs, 简单 ref | 标准拍摄 | 1-3 个月 | 8-12% | 中型 vendor 量产 |
| **C** | 不必 | 标准拍摄 | 1-4 周 | 2-5% | 低成本 vendor / 内部团队 |

#### 9.1 排期红线

- **S 级镜头**至少在拍摄前 **2 个月开始 previs** (Pixomondo 龙之家族 Rook's Rest 战役 previs 5 个月+)
- S/A 级**必须**有 on-set VFX supervisor + tracking marker + HDRI/light probe 数据
- 后期总周期: S 级 = 全片 release 倒推 12 个月起步, A 级 6 个月, B 级 3 个月

#### 9.2 预算红线

- S 级数量 > 全片 20% → 预算几乎必爆 (除非是纯 CG 项目)
- S 级数量 < 5% → 商业大片不够看 (奇观感不足)
- 健康配比: S 5-15% / A 15-25% / B 30-40% / C 30-50% (即 INTERCEPT 样本分布)

---

### 11. 常见误区

1. 错: **只看 ASL 不看 σ** — 一部全程 2 秒 ASL 跟一部快慢交替均值 2 秒的, 节奏完全不同
2. 错: **S 级超 20%** — 除非纯 CG 大片, 否则预算/排期都爆
3. 错: **不分单元只统计全片 ASL** — 看不出节奏起伏
4. 错: **previs 只给 S 级做** — A 级关键段也要 previs (尤其 CG+实拍 互动)
